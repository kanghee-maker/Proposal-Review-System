# Proposal-Review-System

## 0차 부서 평가 통계 배포

1. Next.js 빌드는 서버 번들에만 세션 서명 키를 생성합니다. 새 배포가 적용되면 이전 배포의 로그인 세션은 만료됩니다.
2. 관리자는 기존 비밀번호를 사용합니다. 통계 조회 비밀번호는 관리자의 숫자 비밀번호 각 자리에 1을 더해 서버에서 검증합니다. 9 다음은 0입니다.
3. 관리자 모드의 **0차 평가 통계** 메뉴에서 회차를 선택하고 **통계 인쇄** 또는 **종합 결과 엑셀 다운로드**를 사용합니다.
4. 통계 조회자는 홈의 **0차 평가 통계 조회**에서 전용 비밀번호로 접속해 0차 결과를 조회하고 인쇄합니다.
